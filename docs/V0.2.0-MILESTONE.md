# Lattice v0.2.0 — Milestone Plan

**Decision (Dylan, 2026-06-11):** stop cutting a public release per small patch. Build **v0.2.0**
as a deliberate milestone over **~4–5 full sessions** of fixing, tweaking, auditing, and real
feature work. Accumulate everything on local `master`; **do NOT tag/push a release until the
milestone is complete** (same discipline as the held-back v0.1.5 big update).

Starting point: **v0.1.9** — fleet 5/5, one-click update path production-proven, dashboard fully
offline. The 0.1.x stream hardened the update/cascade machinery; v0.2.0 is about depth: the IDE
feature, closing residuals, hardening identity, and an audit-driven quality pass.

---

## Workstreams (candidates — "they all sound relevant and important" — Dylan)

### A. Mesh editor (IDE Milestone M2-P2) — the headline feature
The embedded VS Code (code-server) editor works on mini-ops only. Make it real across the fleet:
- Install + verify code-server on the darwin machines (studio/mbp/emu) so `editor` sessions launch
  on any Mac (D30); placement already excludes machines without it.
- Windows via **WSL2** (D30) — the harder path; the agent probes WSL + runs the Linux code-server inside.
- Retire the read-only Monaco rail; the embedded editor becomes the editor (D31).
- Decide D28 distribution: per-node install (simple, ~384MB/box) vs hub-served tarball (~95MB, "no
  per-machine install"). Spike notes already in docs/STATE.md "IDE Milestone (M2)".
- (Later/P3) Cursor-grade AI chrome beside the editor (D29).

### B. agentID collision hardening
Two machines with the same hostname collide on one id (`<host>-<os>`) → reconnect duel (the storm
family). Add a persisted per-node nonce to the id. **Risk:** changes enrollment identity on the LIVE
fleet — must preserve existing ids (no orphaned sessions / duplicate fleet rows). Migration-careful.

### C. Residual live-verifications (need Dylan present)
- **/fpreview/ HMR-on-phone** — open a Vite/Next preview on a phone, confirm hot-reload over the tunnel.
- **Telemetry $cost / context% + auto-name** — run one real Claude session; verify the transcript-derived
  telemetry + the free auto-name heuristic render live (closes the v0.1.5 residuals). Needs a billed turn.

### D. Audit-driven quality pass (session 1 — IN PROGRESS)
Four parallel read-only audits seeded this milestone: **security** (auth gating, capability URLs, SSRF in
preview/fpreview, tokens, supply-chain), **backend resilience** (reconnect-storm class, cascade,
SQLite, leaks, timeouts), **frontend/UX** (a11y, state coverage, mobile, type-safety, design drift,
error boundary), **ops/distribution** (installers, cross-OS, release pipeline, docs accuracy, agentID).
Findings get triaged below into fix-now vs backlog.

### E. Polish & doc hygiene
README/STATE/ROADMAP accuracy at v0.1.9; stale "Known minor items"; CHANGELOG `[0.2.0]` assembled at the end.
