| **008** in-panel file viewer | MED | 🔨 plan | DockFiles only downloads; the file API + `marked`+`dompurify` already exist | new `FileViewer.tsx`: fetch via existing `/download`, render markdown (sanitized) / `<pre>` for code; reuse the (now privilege-gated) endpoint. **Low risk, additive.** |
